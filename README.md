# PharmaERP - Premium Pharmacy Management System

PharmaERP is a comprehensive, offline-first, production-ready Java Desktop Application tailored for Indian Medical Pharmacies. It replicates enterprise-level ERP features (like MARG) but provides a clean, modern, and premium white-first design using JavaFX.

## Tech Stack
* **Language**: Java 17+
* **UI Framework**: JavaFX
* **Database**: SQLite (Offline-First)
* **Connection Pool**: HikariCP
* **Migrations**: Flyway
* **Logging**: SLF4J + Logback
* **Security**: jBCrypt
* **Build Tool**: Maven

## Features Implemented in This Phase
* **Application Shell & Theming**: Linear-style UI with `style.css` and JavaFX BorderPanes.
* **Authentication**: BCrypt hashed passwords, role-based login checking against SQLite.
* **Dashboard KPI**: Real-time mockups of dashboard KPIs and navigation bar.
* **Database & Migrations**: Automated SQLite DB initialization `data/pharmacy.db` via Flyway.
* **Medicine Master UI**: Fast-search interface for medicines.
* **POS UI**: Professional billing screen with cart, payment modes, and keyboard shortcut placeholders.
* **Inventory & Purchases**: Starter UI implementations.

## Configuration & Credentials
Database connection and application settings are decoupled from source code using `.env` (or environment variables).
1. Copy `.env.example` to `.env`:
   ```bash
   cp .env.example .env
   ```
2. Configure your MySQL credentials in `.env`:
   ```env
   DB_HOST=localhost
   DB_PORT=3306
   DB_NAME=pharmacy_erp
   DB_USER=root
   DB_PASSWORD=your_password_here
   DB_POOL_SIZE=10
   ALLOW_DEMO_LOGIN=false
   ```
*(Note: `.env` is automatically ignored by Git so secrets won't be leaked)*

## How to Run

1. **Prerequisites**: Ensure Java 21+ and MySQL are installed.
2. **Compile and Run**:
   ```bash
   .\apache-maven-3.9.9\bin\mvn.cmd javafx:run
   ```
   *(or `mvn javafx:run` if Maven is on your system PATH)*
3. **Run from Fat JAR**:
   ```bash
   .\apache-maven-3.9.9\bin\mvn.cmd clean package -DskipTests
   java -jar target/pharmacy-erp-1.0-SNAPSHOT-shaded.jar
   ```

## Directory Structure
* `/data/`: Stores the SQLite database file (`pharmacy.db`).
* `/logs/`: Application logs (generated by logback).
* `/src/main/resources/db/migration/`: Flyway SQL migration scripts.
* `/src/main/resources/fxml/`: UI layouts.

## Packaging as Windows Application
To create a Windows `.exe` installer (requires JDK 17+ with `jpackage` and WiX Toolset):
```bash
jpackage --type exe --input target/ --main-jar pharmacy-erp-1.0-SNAPSHOT-shaded.jar --main-class com.pharmacyerp.Launcher --name PharmaERP --app-version 1.0.0 --win-dir-chooser --win-shortcut --win-menu
```
